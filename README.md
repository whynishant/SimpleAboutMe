# Nishant — Minimalist Portfolio

A fast, lightweight, and typography-first personal portfolio inspired by modern minimalist design principles.

## Features
- **Zero Framework Bloat**: Pure HTML5, CSS3, and vanilla JavaScript.
- **Accurate Aesthetic**: Off-white backdrop (`#faf9f6`), subtle card borders, and refined leading.
- **Dynamic Local Time**: Real-time clock formatted for **Noida, India** (`Asia/Kolkata` timezone).
- **SEO & Social Cards**: Semantic tags, Person Schema (`schema.org`), Open Graph cards, and descriptive meta headers.
- **Modular Multi-page Layout**: Dedicated pages for Photos, Writing, Reading, Work, and Products.

## How to Run Locally
1. Clone or download the folder.
2. Double-click `index.html` to open it in any browser, or use VS Code's **Live Server** extension:
   ```bash
   npx serve .
   ```

## Deploying for Free
- **GitHub Pages**: Push this directory to a repository named `yourusername.github.io` or enable Pages under **Settings -> Pages**.
- **Vercel / Netlify / Cloudflare Pages**: Drag and drop the folder directly into the dashboard for instantaneous global deployment.
